# Meet Wen: Half Artist, Half Data Nerd

## Goal
Build a visually impressive, presentation-ready personal AI profile website for Wen Song.

The site should feel like a personal art gallery + professional portfolio + chatbot.

## Core Theme
Meet Wen: Half Artist, Half Data Nerd

Wen was trained in Chinese traditional painting and dance from age 4. Her father is a Chinese traditional painter, and her mother is a traditional dancer. Wen still paints Chinese paintings, Van Gogh-inspired works, Klimt-inspired works, and original pieces. She also has childhood exhibition photos, dance photos, and travel photos.

Professionally, Wen is a data scientist with experience in federal healthcare analytics, machine learning, NLP, dashboard development, AI/ML, cybersecurity analytics, Splunk, Python, SAS, SQL, Tableau, Power BI, and agentic AI.

## Desired Style
Elegant, warm, artistic, modern, and slightly magical.

The site should blend:
- art gallery elegance
- Van Gogh / Monet inspired warmth
- modern data/AI aesthetic
- clean professional presentation style

## Technical Requirements
- Use Next.js with TypeScript
- Use Tailwind CSS
- Use responsive design
- Use local image placeholders first
- Put images under /public/images/
- Use a local content file first, such as /src/data/aboutWen.ts
- Add chatbot UI, but use a mock response function first
- Later we will connect OpenAI API through a secure server-side route
- No API keys in source code
